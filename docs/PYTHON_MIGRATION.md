# Python 核心算法迁移

## My Fortune 使用的算法

| 模块 | 算法范围 |
| --- | --- |
| calendar.py | 日期与时区处理，夏令时重复/不存在时刻检查，UTC+8 节气历法基准，真太阳时经度修正与均时差 |
| bazi.py | 四柱，十神，藏干，十二长生，纳音，大运顺逆与起运，未知时辰的起运范围，起运前小运 |
| almanac.py | 农历，当日日干支，流日十神，宜忌，冲煞，吉凶神，日九星，节气与胎神方位 |
| relations.py | 天干五合/相冲，地支六合、三合、半合、三会、六冲、刑、害、破，岁运提示与太岁关系 |
| engine.py | 合并个人命盘、目标日期的大运、流年、流月、流日，输出服务使用的统一上下文 |

五项推荐映射及 Qwen 调用仍由 app/rules.py 和 app/recommendations 负责。紫微、塔罗、奇门及其他术数未纳入本次迁移。

## 实现方式

历法与四柱使用固定版本 lunar-python 1.4.9。它是太卜原先依赖的 lunar-javascript 的同作者 Python 实现。节气年/月柱用出生瞬间换算为固定 UTC+8 后计算，日时柱使用本地时间或真太阳时，日柱午夜换日，时干遵循历法库子时规则。

时区使用标准库 zoneinfo。对于实际出生时间，拒绝不存在及重复的夏令时时刻。未知时辰时按当天两端验证年/月柱是否变化，变化则要求补充资料。没有出生日期、性别或出生时区时使用一般黄历主题。

真太阳时采用 astronomy-engine 2.1.19 的 Python 版本，沿用太阳视赤经、恒星时及均时差计算。干支关系组合、焦点去重及起运规则按上游口径改写。

app/taibu.py 保留 TaibuClient.context 调用接口，内部用线程执行 Python 计算。Node、npm 和桥接服务已从运行链路移除。新版规则版本记录在计算结果中，已保存记录默认继续复用。

## 对照与边界

在删除 Node 实现前捕获 20 组上游结果，存为 tests/fixtures/taibu_reference.json。覆盖不同时区、上海夏令时、海外出生、未知时辰、真太阳时和午夜/子时场景，以及立春前和年中目标日期。

自动对照四柱、十神、藏干、十二长生、日干支、宜忌、吉凶神、传统黄历信息、岁运参与柱、叠加干支关系、岁运提示及太岁关系。另测试夏令时跳时/重复和未知时辰遇节气边界的拒绝行为。上下文 JSON 的内部字段组织已经调整，应用对外 Fortune 数据结构保持兼容。

这些对照不代表穷尽历法支持年份或所有节气边界。当前 Patron 入口使用公历、午夜换日、起运算法 1。农历输入、其他换日/起运选项和八字神煞详查尚未作为产品能力提供。真实 Qwen、Yellowbrick 仍需内网联调。
